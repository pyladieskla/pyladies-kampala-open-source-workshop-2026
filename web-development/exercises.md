# PyLadies Kampala Open Source Workshop 2026

## Web Development Practical Exercises

These exercises introduce participants to the basics of web development and give them hands-on experience building a simple website.


## Exercise 1: Create Your First Web Page

Create a file called `index.html`.

Add the basic structure of an HTML document.

Your page should contain:

- A page title
- A main heading
- A short paragraph introducing yourself
- A list of your interests

For example, your page could contain:

    Welcome to My Website

    My name is Brenda and I am learning web development.

    My Interests
    - Python
    - Web Development
    - Open Source

### Challenge

Add an image and a link to a website you like.


## Exercise 2: Working With HTML Elements

Create a personal profile page using HTML.

Your page should contain:

- Your name
- A short biography
- Your education or current work
- Your hobbies
- Your technical interests
- A contact section

Use appropriate HTML elements such as:

- headings
- paragraphs
- lists
- links
- images

### Challenge

Add a navigation section at the top of the page.

---

## Exercise 3: Creating a Simple Form

Create a registration form for a fictional technology workshop.

The form should ask for:

- Full name
- Email address
- Phone number
- City
- Programming experience
- Why they want to attend

Include a submit button.

### Challenge

Add different input types such as:

- text
- email
- number
- radio buttons
- checkboxes
- dropdown/select

---

## Exercise 4: Styling With CSS

Create a file called `style.css`.

Connect it to your HTML page.

Use CSS to change:

- Background colour
- Text colour
- Font size
- Font family
- Spacing
- Borders
- Button appearance

### Challenge

Create a simple card design for your profile.

The card should contain your name, a short description, and a button.


## Exercise 5: Building a Navigation Bar

Create a navigation bar for your website.

Include links such as:

- Home
- About
- Projects
- Contact

Style the navigation bar using CSS.

### Challenge

Make the navigation links change appearance when the user moves their mouse over them.


## Exercise 6: Building a Responsive Page

Modify your website so that it works on both computers and mobile phones.

Use CSS to make sure:

- Text remains readable on smaller screens.
- Images do not overflow the screen.
- Sections stack neatly on mobile devices.
- Navigation remains usable.

### Challenge

Use a CSS media query to change the layout when the screen becomes smaller.

---

## Exercise 7: Create a Simple Project Page

Create a webpage showcasing a project you would like to build.

Your page should contain:

- Project name
- Project description
- Problem the project solves
- Technologies used
- Project features
- Contact or GitHub link

### Challenge

Add screenshots or images representing the project.


# Mini Project: Build a Personal Portfolio

Create a simple personal portfolio website.

The website should contain the following sections:

## Home

Introduce yourself and briefly describe what you do or what you are learning.

## About

Write a short biography and describe your interests.

## Skills

List the technologies and skills you are currently learning.

## Projects

Show at least one project you have worked on or would like to build.

## Contact

Provide a simple contact form or links where people can reach you.


# Optional Challenge: Connect Your Website to Python

If time allows, connect the website to a simple Python program.

Create a Python program that receives information from a user and displays or processes that information.

For example, create a simple registration application where a participant enters:

- Name
- Email
- City

The Python program should process the submitted information.

Participants can use this exercise as an introduction to how Python can be used alongside web applications.


# Final Web Development Challenge

Improve your portfolio website by adding:

- A responsive layout
- Navigation
- A project section
- A contact form
- Basic styling
- Links to your social or GitHub profiles

Test the website in a browser and make sure all links and forms work as expected.


# Learning Outcomes

By the end of these exercises, participants should be able to:

- Understand the basic structure of a webpage.
- Create webpages using HTML.
- Style webpages using CSS.
- Create forms and collect user input.
- Build simple responsive webpages.
- Organize a website into different sections.
- Create a basic personal portfolio.
- Understand how Python can be used with web applications.
