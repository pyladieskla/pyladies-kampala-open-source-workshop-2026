# PyLadies Kampala Open Source Workshop 2026

## Workshop Schedule

**Date:** 28 November 2026  
**Time:** 8:00 AM – 5:00 PM  
**Location:** Kampala, Uganda

The workshop will be a full-day, hands-on learning event. Participants will spend the majority of the day working through practical exercises with support from mentors and facilitators.

---

## 8:00 AM – 9:00 AM
### Registration, Setup and Networking

- Participant registration
- Laptop and development environment setup
- Installation of Python and required tools
- Introduction to the workshop
- Meet and greet with mentors and other participants

---

## 9:00 AM – 10:00 AM
### Introduction to Python

Participants will be introduced to Python programming and work through beginner exercises covering:

- Python syntax
- Variables
- Data types
- User input
- Basic operators

**Hands-on activity:** Python Exercises 1–4

---

## 10:00 AM – 11:00 AM
### Python Programming Fundamentals

Participants will continue with practical Python concepts:

- Conditional statements
- Loops
- Functions
- Lists
- Dictionaries

**Hands-on activity:** Python Exercises 5–9

---

## 11:00 AM – 11:30 AM
### Break

---

## 11:30 AM – 12:30 PM
### Building With Python

Participants will apply the concepts they have learned to build small programs.

Topics include:

- Working with files
- Error handling
- Building a simple calculator
- Building a number guessing game

**Hands-on activity:** Python Exercises 10–14

---

## 12:30 PM – 1:30 PM
### Lunch and Networking

Participants will have lunch and an opportunity to interact with mentors, speakers, and other participants.

---

## 1:30 PM – 2:30 PM
### Introduction to Web Development

Participants will learn the basics of building webpages using:

- HTML
- CSS
- Forms
- Page structure
- Basic responsive design

**Hands-on activity:** Web Development Exercises 1–6

---

## 2:30 PM – 3:00 PM
### Building a Personal Project

Participants will begin building a simple personal portfolio or project webpage.

**Hands-on activity:** Web Development Exercise 7 and Mini Project

---

## 3:00 PM – 3:30 PM
### Introduction to Git and GitHub

Participants will learn how developers manage and collaborate on code using:

- Git
- GitHub
- Repositories
- Commits
- Branches

**Hands-on activity:** Git & GitHub Exercises 1–8

---

## 3:30 PM – 4:00 PM
### Collaborative Development

Participants will practice:

- Creating branches
- Making changes
- Creating Pull Requests
- Reviewing contributions
- Merging changes

**Hands-on activity:** Git & GitHub Exercises 9–14

---

## 4:00 PM – 4:45 PM
### Your First Open Source Contribution

Participants will go through the basic open-source contribution workflow:

- Finding an open-source project
- Understanding contribution guidelines
- Finding beginner-friendly issues
- Forking a repository
- Creating a branch
- Making a contribution
- Creating a Pull Request

**Hands-on activity:** Open Source Contribution Exercises

---

## 4:45 PM – 5:00 PM
### Wrap-Up and Next Steps

- Participant reflections
- Questions and answers
- Sharing opportunities for continued learning
- Open-source contribution opportunities
- Community announcements
- Closing remarks

---

## Learning Approach

The workshop will use a hands-on learning approach. Participants will spend significant time writing code, completing exercises, building small projects, and working with mentors.

Mentors will be available throughout the practical sessions to help participants troubleshoot problems, understand concepts, and complete their projects.

Participants will also be encouraged to continue practising after the workshop using the exercises and resources provided in this repository.
